Accessibility UI Tester

Unity Editor extension detecting colour-vision UI failures: GPU CVD simulation, a WCAG contrast meter and JSON reporting.

  • Unity 6
  • C#
  • URP
  • Render Graph
Project breakdown for Accessibility UI Tester

MSc Individual Research Project under Philip Edwards, targeting correctness of detection and computational cost for colour-related UI accessibility failures. All five build phases and evaluation are complete.

Contributions and systems

  • URP Render Graph shader feature simulating protanopia, deuteranopia and tritanopia with Machado et al. (2009) CVD matrices, verified to a colour deviation of 0.0000 against reference data at ~420fps
  • Click-driven WCAG 2.1 contrast checker via EventSystem raycasting with alpha-compositing
  • Automated whole-scene accessibility scanner, JSON-exporting; fixed an N+1 rendering regression for an 8.6x speed-up (4.3s → 499ms per 1,000-element scan)
  • Global TMP font scaler with revertible caching and RectTransform overlap detection
  • Validated via a labelled ground-truth benchmark and reproducible Python scoring script: Precision 0.917, Recall 1.000, F1 0.957
  • Packaged as an MIT-licensed, one-click-importable Unity package with a full unit and integration test suite

Reach the summit ring or survive five minutes. This interactive browser demo is a simplified recreation of the gameplay. Contributions and systems

  • Twelve spiral platforms, five moving side routes, a summit goal and a five-minute survival objective

  • Simplified browser demo adds checkpoints and local records; it is a separate recreation of the native game
  • Camera-relative movement, keyboard and touch controls, drag/Q/E camera rotation, pause on focus loss and synthesised sound effects
  • Native C++17/OpenGL engine source, Bullet collision integration, FMOD audio integration and retained third-party notices
